# 🚀 Day 11 Summary

Today I learned how to use loops for repetitive tasks and how to combine loops using **nested loops**.

The most important concept:

```text
Outer Loop
    ↓
Inner Loop runs completely
    ↓
Outer Loop moves to next iteration
    ↓
Inner Loop runs completely again
```
