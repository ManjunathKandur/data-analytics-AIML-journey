# Day 10 – Conditional Statements

> Python decision-making using `if`, `elif`, `else`, nested conditions, and Boolean logic.

## Topics Covered

- `if` statement
- `if...else`
- `if...elif...else`
- Nested `if` statements
- Boolean logic (`and`, `or`, `not`)
- Comparison operators

## What I Learned

- How to execute code based on conditions
- Difference between `if`, `elif`, and `else`
- Using nested conditions for multiple decision levels
- Combining multiple conditions with Boolean operators
- Writing real-world decision-making programs

## Key Concepts

| Concept | Purpose |
|---------|---------|
| `if` | Execute when a condition is true |
| `elif` | Check another condition |
| `else` | Default execution block |
| Nested `if` | Decision inside another decision |
| `and` | All conditions must be true |
| `or` | Any one condition can be true |
| `not` | Reverse a Boolean value |
