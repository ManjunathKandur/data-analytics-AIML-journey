# Day 09 – Python Dictionaries

> Learning Python dictionaries through hands-on practice and mini projects.

## Overview

Day 9 focuses on **Dictionaries**, one of Python's most important data structures for storing data as **key-value pairs**. This module covers creating dictionaries, accessing values, updating data, removing items, and iterating through records.

## Topics Covered

- Key–Value pairs
- Creating dictionaries
- Accessing values
- Adding new items
- Updating existing values
- Removing items (`pop()`, `del`, `clear()`)
- Dictionary methods:
  - `.keys()`
  - `.values()`
  - `.items()`
- Looping through dictionaries

## Practice Programs

1. Student Database

6. Number Frequency Counter

## Key Concepts Learned

| Method | Purpose |
|---------|----------|
| `dict[key]` | Access a value |
| `.get()` | Safely retrieve a value |
| `.keys()` | Get all keys |
| `.values()` | Get all values |
| `.items()` | Get key-value pairs |
| `.pop()` | Remove a specific item |
| `del` | Delete a key |
| `.clear()` | Remove all items |
