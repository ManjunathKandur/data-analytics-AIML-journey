# 📘 Day 02 — Data Types in Python


Today, I learned the foundation of Python programming by understanding **Data Types** and **Type Conversion**. Every value in Python belongs to a specific data type, and knowing how to identify and convert them is essential for Data Analytics, Machine Learning, and AI applications.

---

## 📚 Topics Covered

- Integer (`int`)
- Float (`float`)
- String (`str`)
- Boolean (`bool`)
- None (`NoneType`)
- `type()` function
- Type Conversion (`int()`, `float()`, `str()`, `bool()`)

## 🎯 Key Takeaways

- `int` stores whole numbers.
- `float` stores decimal numbers.
- `str` stores text.
- `bool` stores `True` or `False`.
- `None` represents the absence of a value.
- `type()` helps identify the data type of any object.
- Type conversion allows changing data from one type to another safely.
