## 🧠 Key Concepts

### 🔹 Indexing
Access individual characters using positive and negative indexes.

```python
text = "Python"

print(text[0])   # P
print(text[-1])  # n
```

### 🔹 Slicing
Extract portions of a string.

```python
text = "Analytics"

print(text[0:4])   # Anal
print(text[::-1])  # Reverse string
```

### 🔹 String Methods

| Method | Purpose |
|---------|---------|
| `upper()` | Convert to uppercase |
| `lower()` | Convert to lowercase |
| `title()` | Title case |
| `strip()` | Remove extra spaces |
| `replace()` | Replace text |
| `count()` | Count occurrences |
| `split()` | Convert string to list |
| `join()` | Join list into string |

### 🔹 String Formatting

```python
name = "Manjunath"
print(f"Hello, {name}!")
```

### 🔹 Escape Characters

```python
print("Hello\nWorld")
print("Name:\tManjunath")
```
