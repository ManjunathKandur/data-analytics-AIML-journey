# 📘 Day 07 — Tuples & Mutability

Welcome to **Day 07** of my **100 Days of Data Analytics & AI/ML Challenge**.

## 📚 Topics Covered

- Tuples
- Creating tuples
- Indexing & slicing
- Tuple methods (`count()` and `index()`)
- Tuple unpacking
- Mutable vs Immutable
- Lists vs Tuples

## 💻 Practice Programs

- Coordinate System
- Student Records
- Count Occurrences in a Tuple
- Variable Swapping using Tuple Unpacking
- Topper Finder

## 🧠 Key Concepts

| List | Tuple |
|------|------|
| Mutable | Immutable |
| Uses `[]` | Uses `()` |
| Can add/remove items | Cannot be modified |
| Best for dynamic data | Best for fixed data |
